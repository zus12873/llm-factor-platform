## 七、浏览器验收抓到而单测抓不到的缺陷

记录在此，因为它们说明了两类测试各自的边界：

1. **点击后界面毫无反应** —— 后端返回 502（模型未配置，正确行为），前端只处理了版本冲突，其余错误被静默吞掉。12 条单测全绿。
2. **antd v5 与 React 19 不兼容** —— 控制台持续告警，已降到 React 18.3。
3. **行复选框用 `name` 而非 `aria-label`** —— 屏幕阅读器不播报，用户无法知道每个复选框选的是哪一行绑定。
4. **真实 OCR 引擎的图像解码** —— 我把 PNG 原始字节直接喂给识别器，fake 引擎永远碰不到图像。
